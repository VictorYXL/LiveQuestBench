# Superseded learning definitions

The four YAML files preserve the Minecraft workshop and Veloren glide learning
candidates before their replacement by native route-schema transfer on
2026-10-28. Paths inside these unchanged YAMLs are relative to their original
`config/<game>/tasks/<track>/` locations; this is a source-definition archive,
not a standalone runnable copy. Historical fixture worlds and execution
artifacts remain in their original local locations.

`retired_tests/test_expedition.py` preserves regression tests for Minecraft
expedition implementations removed in commit `31cf02c`. It is outside active
test discovery and is not counted as a passing check. The retained generic
state scorer's passive action checks remain in the active test suite.

The active catalog and evidence limits are documented in
[`reference_tasks_release_20261028.md`](../../survey/reference_tasks_release_20261028.md).
